## 실제 관찰과 추론

2026-10-09 Chromium에서 아래 세 사이트를 각각 1440×900과 390×844로 열었습니다. 여섯 번 모두 `net::ERR_TUNNEL_CONNECTION_FAILED`, 별도 HTTP 요청은 `403 Tunnel connection failed`였습니다.

접속 시도 JSON은 `reference-access.json`, 브라우저 오류 캡처는 검수 아카이브의 `references/`에 있습니다. 접근하지 못한 사이트의 애니메이션을 관찰했다고 보고하지 않습니다. 아래는 해당 설명과 고또마케팅의 실제 업무를 바탕으로 새롭게 설계한 결과이며, 사이트의 코드·그래픽을 가져오지 않았습니다.

## 공통 브랜드 원칙

고객은 한국의 안경원 원장님과 운영자입니다. 주인공은 판매할 안경이 아니라 매장의 전문성을 콘텐츠와 채널에 담는 업무입니다. 검증된 고객 프로젝트 원자료나 공개 동의가 없어 가짜 포트폴리오를 넣지 않았습니다. B의 종이 그래픽은 브랜드 콘셉트, C의 문안은 구성 예시로 표시합니다.

## 시각 검수에서 바뀐 내용

A의 촘촘한 표면 무늬가 소프트웨어 렌더링에서 모아레를 만들던 문제를 주파수 축소와 픽셀 미분 필터로 줄였습니다. 설명이 전부 사라지던 중간 구간도 이전·다음 헤드라인의 인계로 수정했습니다.

B 모바일의 세로로 쪼개진 CTA를 가로 링크로 고쳤고, 중간 지면에서 다음 제목이 더 일찍 완전히 읽히도록 조정했습니다. C는 앞면이 뒤 본문을 잘라 보이던 타이밍을 분리하고 작은 모바일 캡션을 확대했습니다.

실제 휠 입력에서도 B/C의 고정 장면 진입·종료 시 레이아웃 이동이 측정되어, 두 장면은 GSAP의 pin 대신 높이가 미리 확보된 CSS sticky로 바꿨습니다. ScrollTrigger는 모션 진행에 사용합니다. B의 큰 그림자와 이미지 필터 비용도 줄였으며 최종 측정값은 QA 보고서에 구분해 기록합니다.

기능 성공이나 협업 인원수를 시각 품질의 근거로 삼지 않습니다. 이번 산출물은 사용자가 직접 비교할 세 가지 방향이며, 수상 수준 달성이나 최종 디자인 승인을 자체 선언하지 않습니다.
