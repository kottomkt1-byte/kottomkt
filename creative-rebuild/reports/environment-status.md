# 실행 환경과 설정 저장 상태

현재 인스턴스에서 Node 24.19.0, npm 11.9.0, Python 3.12.14, Chromium 151, Python Playwright 1.62.0, Pillow 12.3.0, 시스템 FFmpeg를 사용했습니다. 독립 프로토타입의 의존성 설치·Vite 시작·배포 빌드·브라우저 자동화가 실제 실행되었습니다.

`npm ci --ignore-scripts`의 기본 캐시 경로가 읽기 전용이라 처음에는 실패했습니다. 작업용 `npm_config_cache`를 지정한 잠금 파일 기반 재설치는 성공했고 빌드도 다시 통과했습니다. 패키지 무결성 검증·TLS 검증을 끄지 않았습니다.

클라우드 설정 초안에 재현용 설치/시작 절차와 레퍼런스·Playwright 다운로드 도메인을 추가하려 했으나 **`stale_base / CONFLICT`**로 저장되지 않았습니다. 이미 게시되거나 바뀐 환경 버전보다 이 대화의 초안이 오래됐다는 응답입니다. 네트워크 변경과 새 환경 게시를 완료했다고 주장하지 않습니다.

재사용 가능한 제안은 `environment-proposal.json`, `environment-install.sh`, `environment-start.md`에 보존했습니다. 별도 환경 재설정이 필요하면 현재 환경 설정에서 새 설정 대화를 열고 제공한 환경 제안 ZIP을 전달해 최신 초안과 조정해야 합니다. 기존 허용 도메인을 무조건 덮어쓰는 절차가 아닙니다. 승인 질문 때문에 프로토타입 제작을 중단하지 않았습니다.

코드·폰트·이미지·공식 Playwright 스킬은 Git 브랜치에 보존합니다. 새 Cloud 작업에서는 `codex/kotto-creative-rebuild`를 선택해 체크아웃해야 합니다. 살아 있는 서버 프로세스나 이번 대화의 브라우저 세션은 새 작업에서 유지된다고 가정하지 않습니다. `main` 병합이나 운영 배포는 하지 않았습니다.

공개 Preview 환경은 아직 없습니다. Vercel 연결 정보와 배포 인증은 없고, GitHub API/Pages 조회는 403이었습니다. Git 저장소 접근과 호스팅 API 배포 권한은 별개입니다. `dist/`만 별도 정적 사이트 프로젝트에 배포하는 절차는 README에 있습니다.
