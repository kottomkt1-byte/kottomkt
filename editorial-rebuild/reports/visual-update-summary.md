# 실제 작업물과 고객 반응을 중심으로 한 B형 업데이트

2026-10-09 작업 기록. 아래는 실제 구현과 Chromium 브라우저 검수 결과다.

## 바꾼 내용

고또마케팅은 한국의 안경원 원장과 운영자를 대상으로 광고대행·콘텐츠 마케팅을 제공한다. 안경 판매 사이트로 보이지 않도록 실제 마케팅 제작물과 고객 대화를 중심에 두었다. 기존 12페이지, 서비스 7개, 문의·연락·지도 기능을 유지하며 메인·회사 소개·브랜드 블로그 상세·홈페이지형 블로그 상세의 시각 자료를 보강했다.

- **실제 제작 화면 7개:** 각 안경원의 홈페이지형 블로그를 크게 보고, 썸네일이나 이전·다음 버튼으로 선택한다.
- **고객 반응 15개와 상담 문의 8개:** 기존 공개 캡처를 복원하고 분류 전환·더 보기·원문 크게 보기를 제공한다.
- **공통 이미지 뷰어:** 원본 전체 비율, 확대해서 읽기, 이전·다음, Escape 닫기, 닫은 뒤 초점 복귀를 구현했다. 기존 가림 처리와 이미지 내용은 변경하지 않았다.
- **업무를 보여주는 편집 장면:** 안경 소재의 브랜드 이미지, 고객에게 설명할 문장, 실제 제작 화면이 하나의 화면으로 모이도록 구성했다.
- **강점 기록:** 사용자가 현재 사용을 확인한 네 수치를 원래 범위대로 메인과 회사 소개에 복원했다.

새로운 성과 사례나 고객을 만들지 않았다. 30개 이미지의 원본 커밋·현재 저장소·설치 사본 SHA-256은 모두 일치한다. 파일별 치수·용량·해시는 [evidence-manifest.json](evidence-manifest.json)에 있다.

## 네 수치의 사용 근거

사용자는 2026-10-09 “현재도 사용하는 수치입니다”라고 확인했다.

| 값 | 의미 |
| --- | --- |
| 5,000건+ | 안경 제작 사례 작성 |
| 100% | 메인 품목 재계약률 |
| 98% | 전문성 만족도 |
| 2위 | 에실로 얼티밋 전국 순위 |

이는 사용자의 현재 사용 확인이며 독립적인 원자료 감사와 구분한다. 집계 기간, 대상 계약 수, 설문 조건, 순위 대상자를 추가로 추정하지 않았다. 개별 대화 속 변화도 전체 고객의 평균·보장 결과로 옮기지 않았다. 자세한 이미지·인용·수치 판단은 [evidence-source-audit.md](evidence-source-audit.md)에 있다.

## 검수 상태

1440px·390px의 일반/축소 모션 조합으로 변경된 4페이지를 검사한 16개 상세 사례와 전체 12페이지×2폭 회귀 검사를 마쳤다. 콘솔 오류와 가로 넘침, 초기 CLS는 모두 0이었다. 원본 이미지 30개는 두 화면 폭의 큰 보기에서 모두 디코딩되었고 이미지 전체 비율, 확대, 좌우키, Escape, 초점 복귀가 통과했다.

모바일 가로 갤러리의 화면 밖 lazy 이미지를 최초 smoke 검사에서 누락으로 집계한 오류는 화면 교차 기준으로 교정했다. 별도로 홈과 홈페이지형 블로그의 7개 카드씩 총 14개를 실제 선택·디코딩하여 누락이 없음을 확인했다. JS 비활성화 상태에서도 원본 링크 7+15+8개가 보이고 원본 이미지로 이동했다. 수치 네 개의 라벨·값과 가림 여부를 두 폭에서 확인했다.

네이티브 wheel 정·역방향 검사에서 제작 사례는 0→2→0, 편집 장면도 시작 상태로 돌아왔다. 테스트 환경의 RAF p95는 16.7–16.8ms, 34ms 초과는 0이었다. 이는 에뮬레이션의 관찰이며 실제 저사양 휴대폰의 GPU 성능을 측정한 결과가 아니다. 초기 검사와 보충 결과는 `visual-update-results.json`, `visual-update-supplemental.json`에 기록했다.

단일 파일 간편 보기는 HTTP로 한 번 불러온 뒤 브라우저를 오프라인으로 전환해 12페이지×2폭, 원본 이미지 30개×2폭, 확대·페이지 이동·뒤로가기·문의 자동 입력을 검수했다. 오류와 추가 HTTP 요청은 0이었다. 관리형 Chromium에서 직접 `file://` 열기는 차단되므로 더블클릭 동작을 직접 테스트했다고 주장하지 않는다. 배포 폴더는 12페이지·54개 파일·원본 30개의 바이트 보존과 링크 검사를 통과했다.

브라우저 검수 범위는 1440px 데스크톱·390px 모바일, 일반·축소 모션, 시작·중간·종료 스크롤 상태, 30개 이미지와 뷰어, 키보드·터치, 12페이지 회귀, 외부 전송을 막은 문의 폼 검사다. 녹화와 실제 화면을 함께 확인하며 기능 통과를 시각 완성도 승인으로 간주하지 않는다. 세부 계획은 [visual-update-plan.md](visual-update-plan.md)를 따른다.

자세한 결과와 한계는 [visual-update-qa.md](visual-update-qa.md)에 있다. 실제 Chromium 프레임으로 만든 영상은 데스크톱 40.92초, 모바일 37.04초이며 `share/recordings/kotto-visual-update-desktop.mp4`, `kotto-visual-update-mobile.mp4`로 제공한다. 정지 이미지를 이어 붙인 모션 시뮬레이션이 아니다.
