# 기존 제작 사례와 실제 고객 반응 복원 감사

## 이번 작업의 범위

사용자는 새 B형 홈페이지에 기존에 공개했던 실제 제작 결과, 고객 반응 캡처와 브랜드의 강점을 다시 보여달라고 요청했다. 이 요청을 기존 공개 이미지 복원의 명시적 승인으로 적용했다. 앞선 콘텐츠 감사에서 공개 동의 원자료를 확인하지 못했다는 기록을, 사용자가 요청한 복원을 다시 막는 이유로 사용하지 않았다.

복원 대상은 홈페이지형 블로그 제작 화면 7개, 고객 후기 대화 15개, 상담 문의 대화 8개다. 새로운 후기·고객·성과를 만들지 않았다. 원본 이미지에서 개인정보를 복원하거나 가림 처리를 제거하지 않았다.

## 실제 확인한 원본

- 현재 저장소 `images/portfolio/portfolio-01.png`부터 `portfolio-07.png`까지 7개.
- 현재 저장소 `images/reviews/review-01.png`부터 `review-15.png`까지 15개.
- 현재 저장소 `images/nosales/chat-01.png`부터 `chat-08.png`까지 8개.
- 리디자인 전 커밋 `58e34ce81f7efb03924db646aba2771b64c5e6bc`의 `index.html`, `about.html`, `service-hpblog.html`을 직접 읽고 이미지의 사용 맥락과 포트폴리오 상호를 확인했다.
- 위 커밋의 PNG 30개도 `git show`로 읽어 현재 저장소의 원본과 대조했다.

30개 이미지를 8개 확인용 묶음 이미지로 만들어 `view_image`로 모두 열었다. 인용과 세부 맥락을 위해 `review-01.png`, `review-05.png`, `review-09.png`, `review-12.png`, `chat-07.png`는 원래 해상도로 별도 열었다. 확인용 묶음 이미지는 작업 공간의 감사 보조 자료이며, 웹사이트에는 사용하지 않는다.

## 설치 경로와 바이트 검증

공개용 사본은 `editorial-rebuild/public/evidence/`에 PNG 파일명 그대로 저장했다. 파일 재인코딩, 크기 변경, 텍스트 덧붙이기, 흐림 제거, 색 보정 등 픽셀 변경을 하지 않았다.

**30개 모두 `원본 커밋 PNG = 현재 images PNG = public/evidence PNG`의 SHA-256이 일치한다.** 전체 용량은 1,309,581바이트다. 각 파일의 전체 SHA-256, 너비·높이, 용량과 경로는 같은 폴더의 `evidence-manifest.json`에 기록했다.

복원된 데이터 모듈은 `src/evidence-data.js`이며 다음을 내보낸다.

- `portfolio` / `evidencePortfolio`: 제작 사례 7개.
- `reviews` / `evidenceReviews`: 고객 후기 15개.
- `inquiries` / `evidenceInquiries`: 상담 문의 8개.
- `allEvidence`: 위 배열을 합친 전체 30개.

각 항목은 `key`, `id`, `src`, `width`, `height`, `title`, `caption`, `alt`, `kind`를 제공한다. 제작 사례는 `name`, 직접 확인한 일부 후기만 선택적 `quote`를 제공한다. `src`는 `evidence/portfolio-01.png` 같은 상대 경로다.

## 후기와 문의의 해석 범위

고객 대화에는 작업한 글에 대한 반응, 함께 일하며 전한 감사, 매장 운영과 문의에 관한 개인 경험이 담겨 있다. 캡처에 실제로 적힌 경험은 보존하되 모든 고객의 평균 결과나 매출 상승 보장으로 확대하지 않는다.

- 후기 01·03·09는 글을 읽고 전한 반응을 보여준다.
- 후기 04·05·08은 작업과 협업에 대한 개별 고객의 반응을 보여준다.
- 후기 07·10·11·14·15에는 유입·매출·운영 변화 등에 관한 고객의 말이 포함된다. 독립적인 매출 장부 검증이나 인과 분석을 한 자료가 아니다.
- 후기 12는 자료의 활용 가능성을 말하면서 전문적인 내용은 다시 확인할 부분도 있다고 적고 있다. 긍정적인 앞부분만 이용해 '오류가 없다', '검토가 필요 없다'고 해석하지 않는다.
- 후기 13은 바쁜 매장 일상에 관한 대화다. 특정 수치나 채용 완료를 새로 주장하지 않는다.
- 문의 8개에는 당시 신규 모집, 다음 시즌, 대기·알림에 관한 질문이 담겨 있다. 과거 문의 기록이 현재 모집 마감·대기 인원·희소성의 근거가 되지 않도록 중립적인 '상담 문의' 명칭을 사용했다.

이미지에 이미 들어 있는 흐림·모자이크·가림·강조 박스를 그대로 보존했다. 따라서 표시 문구는 '기존에 공개한 대화 캡처'가 정확하며, 최초 대화에 어떤 편집도 없었다는 의미의 '무편집 원본'이라고 새로 주장하지 않는다.

## 기존 수치의 현재 사용 확인

2026-10-09 사용자는 기존 네 수치에 대해 **“현재도 사용하는 수치입니다”**라고 명시적으로 확인했다. 이 최신 확인에 따라 기존 의미와 범위를 유지해 다음 네 항목을 복원한다.

| 값 | 복원하는 원래 의미 |
| --- | --- |
| 5,000건+ | 안경 제작 사례 작성 |
| 100% | 메인 품목 재계약률 |
| 98% | 전문성 만족도 |
| 2위 | 에실로 얼티밋 전국 순위 |

확인 상태는 **사용자의 현재 사용 확인**이다. 원자료를 독립적으로 감사한 결과와 구분한다. 집계 기간, 재계약률의 대상 계약 수, 만족도 조사 조건, 순위 대상자에 관한 별도 정보는 제공되지 않았으므로 새로 기입하지 않는다. 사례 작성 건수를 제작한 안경 수나 고객 수로 바꾸거나, 메인 품목 재계약률을 전체 서비스 재계약률로 확대하지 않는다.

이 확인은 앞선 `content-audit.md`에 기록한 수치 보류 사유 중 현재 사용 여부에 관한 판단을 갱신한다. 해당 감사는 당시 확보한 근거를 기록한 것이며, 네 수치의 복원 판단에는 이번 사용자 확인을 우선 적용한다. 이미지 복원과 바이트 검증 결과는 그대로 유지한다.

## 사용한 지침

이 작업은 앞선 턴에서 실제 읽은 `.agents/skills/kotto-korean-copywriter/SKILL.md`와 해당 `references/business-facts.md`, `references/claims-and-cases.md`, `references/korean-voice.md`를 적용했다. 문장을 새로 지어내지 않고 고객 원문·고유명사·부정·범위를 보존했다. 사용자의 최신 복원 요청이 일반적인 보류 지침보다 우선한다. 스킬 파일은 변경하지 않았다.
