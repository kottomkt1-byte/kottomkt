# 안경 산업으로의 범위 확대 — 2026-11-09

사용자는 디자인 레퍼런스를 활용한 품질 개선과 함께 안경원 외 안경 관련 업종까지 포괄하도록 홈페이지를 수정해 달라고 요청했다.

## 변경

- 공통 분류를 **안경 산업 전문 광고·콘텐츠 마케팅**으로, 메인 메시지를 **안경을 아는 시선. 브랜드를 위한 콘텐츠.**로 변경했다.
- 메인에는 안경원, 아이웨어 브랜드, 안경렌즈·콘택트렌즈, 제조·유통 및 관련 기업을 안내한다. 각 분야에서 해당 업종의 서비스 목록으로 이동한다.
- 원본 화보와 여백·타이포그래피를 중심으로 첫 화면, 분야 소개, 비대칭 작업 소개, 서비스 묶음을 구성했다. 배경 영상의 재생 버튼·필름 링크·캡션은 계속 숨긴다.
- 서비스 목록에 업종 필터를 추가하고 상세 설명을 넓혔다. 플레이스·당근은 안경원 전용, 모델 이미지는 안경테·선글라스 대상으로 유지한다.
- 회사 소개를 실제 화보·블로그 작업과 네 분야의 업무 중심으로 정리했다. 문의 양식은 기업/브랜드명과 연락처를 받고 매장명·지역·담당자·이메일은 선택으로 처리한다. 업종, 프로젝트/월 운영 유형, 해당 예산 설명을 제공한다.
- 문의 전송은 기존 EmailJS 서비스·템플릿·공개 키와 6개 payload 키를 유지한다. 추가 맥락은 message 안에 넣는다. 대표전화·국제번호를 훼손하던 자동 형식 변경을 제거했다.
- 13개 페이지의 제목·설명·공유 메타데이터와 공유 이미지를 새 범위에 맞췄다. 브랜드 필름 본편도 업종 전체를 아우르는 문구로 갱신했다.
- 원본 포트폴리오 32장, 실제 고객 증거 이미지, Optical 포트폴리오 #23, ZIN 01 뷰어, 법정 정보는 유지한다. 기업 고객·렌즈 기업의 실적을 새로 만들지 않았다.

디자인 참고의 출처와 실제 적용 원칙은 [DESIGN.md](../DESIGN.md)에 있다. 참고 사이트의 애니메이션 구현을 확인했다고 주장하지 않는다.

## 검수

- `npm run build:production`, `python scripts/verify-build.py`: 13페이지, 원본 증거 이미지 30개 검증 통과.
- `python qa/industry-audit.py`: 1440/390px × 13페이지, **26개 화면 조합 통과**. 제목·로컬 앵커·공유 메타데이터, 실제 이미지 로딩, 가로 넘침, JavaScript/HTTP 오류 검사. 홈페이지 → 렌즈 기업 서비스 → 업종 필터 → 모델 이미지 상세 → 문의 사전 선택과 키보드 메뉴 동작 확인.
- `python qa/company-industry-audit.py --base http://127.0.0.1:4186`: 1440/390/320px 통합 문의 검수 통과. 필수 항목, 선택 이메일, 기업 문의 fallback, 대표/국제전화, 업종/예산 맥락, 중복 전송 차단, 실패 입력 보존, 성공 초기화를 확인했다. **SDK 모킹 및 API 차단, 실제 이메일 전송 없음.**
- `python qa/brand-film-audit.py`: 일반 데스크톱/모바일/320px, 동작 감소, 데이터 절약, JS 비활성화의 6개 조건 통과. 무음 22초 영상 동작, 홈페이지 위 표시 제거, 본편 자동 다운로드 없음 확인.
- 1440/390px 실제 첫 화면, 분야 소개, 작업 소개, 서비스, 푸터를 직접 시각 검토했다. 고정 헤더가 전체 요소 캡처에 겹치는 자동화 캡처 특성은 일반 뷰포트 캡처와 구분했다.
- 신규 본편: 26초, 1920×1080, 24fps, H.264/AAC, 6,664,067바이트. 전체 디코딩 및 장면 시각 검수 통과. 무음 히어로 자산·원본 음악은 변경하지 않았다.

브라우저 검수는 Chromium의 화면 크기 에뮬레이션이다. 실제 기기 성능이나 운영 메일 수신을 테스트한 것으로 해석하지 않는다. 결과는 `industry-qa.json`, `company-industry-qa.json`, `kotto-seen-film-qa.json`, `kotto-industry-film-update.json`에 보존한다.
