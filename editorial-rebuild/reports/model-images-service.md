# 안경테·선글라스 모델 이미지 제작 서비스

작업일: 2026-11-04

## 구현

고또마케팅의 새 서비스 페이지 `service-model-images.html`을 홈 서비스 목록, 전체 메뉴, 서비스 디렉터리와 문의 양식에 연결했다. 자체 개발 프로그램을 활용한 제작과 안경사의 직접 검수를 설명한다. 가격·납기는 상담으로 안내하며, 문의 버튼은 해당 서비스의 상담 문구를 자동 입력한다.

큰 타이포그래피와 사용자 제공 화보, 스크롤 등장·이미지 이동 모션을 구성했다. 검수 포인트를 선택하는 안경 구조 도해, 선글라스·안경테 포트폴리오, 제작 과정과 FAQ를 포함한다. 도해는 특정 제품의 실측 도면이 아니다. GSAP 모션은 모션 감소 설정을 따른다.

편집 원본: `src/model-images.js/css`, `src/model-gallery.js/css`, `src/model-portfolio-data.js`.

## 이미지와 표현의 출처

사용자가 분할 ZIP 3개로 제공한 원본 32장(선글라스 23장·안경테 9장)을 모두 반영했다. 각 원본은 1122×1402 PNG다. 표시용 900px WebP와 확대용 전체 해상도 lossless WebP를 제공하며, 확대용 파일은 원본과 RGB 픽셀이 같은지 전수 대조했다. 색상·제품·인물·배경을 수정하지 않았다. 출처, 파일별 SHA-256과 픽셀 대조 기록은 `model-images-asset-provenance.json`에 있다. 레이아웃 개발 중 사용한 임시 생성 사진은 최종 자산에서 제거했다.

자체 개발 프로그램과 안경사 직접 검수는 사용자가 제공한 사업 정보다. `국내 유일`, `오차 없음`은 비교 조사 및 정확도 보장 범위 자료가 없으므로 사용하지 않았다. 가격, 납기, 수정 횟수, 이용 조건과 수상 이력도 임의로 만들지 않았다.

## 검수

- Vite: 13페이지, 운영 파일 132개 생성.
- 정적 파일 검증: 페이지 연결 및 기존 고객 원본 이미지 30개 보존 확인.
- 신규 페이지: 320·390·768·1440px의 가로 넘침, 검수 항목 버튼, 키보드 조작, FAQ 확인. `model-images-visual-qa.json` 참고.
- 실제 포트폴리오: 32장 디코딩, 선글라스 23장·안경테 9장 필터, 더 보기, 전체 해상도 확대, 방향키·Escape·포커스 복귀·트랩 확인. 모션 감소 및 JavaScript 비활성화도 확인. `model-gallery-real-qa.json` 참고.
- 운영 빌드: 13페이지의 PC·모바일 26개 화면, 132개 파일 해시와 검색 메타데이터, 기존 영상·메뉴·문의 기능, 새 서비스 이동 및 문의 자동 입력 통과. `production-qa.json` 참고. 문의 API는 차단하고 SDK를 모킹했으며 실제 메일을 발송하지 않았다.
- 마지막 갤러리 제목 공백 수정 후 운영 manifest와 신규 페이지 320·390px를 별도 재검수하여 통과했다. 결과는 `model-images-release-check.json`에 기록했다.

Chromium의 네이티브 문서 전환이 페이지 이동 시 `AbortError: Transition was skipped`를 발생시켜 자동 문서 전환만 비활성화했다. 페이지별 GSAP 모션은 유지하며 오류를 숨기는 전역 예외 처리는 추가하지 않았다.

운영 배포는 기존 GitHub Pages `main` 저장소 루트를 사용한다. `build:production` 결과를 manifest로 검증한 후 `apply-production.mjs --apply`로 적용하며, 이전 루트 파일은 저장소 바깥에 백업한다.
