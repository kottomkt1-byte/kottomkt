# 12페이지 미디어 업데이트

2026-10-09 · `codex/kotto-creative-rebuild` · 구현 경로 `editorial-rebuild/`

이번 요청은 B 에디토리얼 방향을 유지하면서 홈페이지 전체의 사진·영상·일러스트를 보강하는 것이었다. 고또마케팅은 한국 안경원 원장과 운영자를 위한 광고대행·콘텐츠 마케팅 회사다. 안경 판매 사이트처럼 보이지 않도록 콘텐츠 기획, 편집, 촬영 소재, 지역의 고객 접점을 시각화했다.

## 실제 변경 범위

| 페이지 | 현재 구성 |
| --- | --- |
| 메인 | 브랜드 영상 히어로 → 제작 과정의 3개 장면 → 강점 기록 4개 → 사진·일러스트 서비스 표지 3개와 전체 서비스 목록 → 후기 15개·문의 8개 |

사용자 요청에 따라 **메인의 홈페이지형 블로그 사례 갤러리는 제외했다.** 7개 사례는 해당 서비스 상세에서 유지한다. 이전 메인의 브랜드 필름 섹션과 종이 WebGL 장면은 현재 메인 흐름에서 제거했다. 후기·문의 23개와 확대 보기는 유지하며, 원본 공개 이미지 30개의 내용·가림 처리를 바꾸지 않았다.

문의 필드와 EmailJS service/template/payload, 카카오톡·이메일·블로그·주소·지도 연결은 유지한다. 새로운 고객 사례, 성과, 운영 경력은 추가하지 않았다. 서비스 화면의 선택 예시는 설계·업무 설명이며 실제 고객 산출물이라고 제시하지 않는다.

## 이미지와 영상

기존 브랜드 아트 3개에 사진 스타일 이미지 2개, 손그림 스타일 일러스트 2개를 추가했다. 이 네 이미지는 OpenAI 이미지 생성 도구로 실제 제작했다. 고객 원본을 생성 도구에 넣거나 고객 캡처를 수정하지 않았다.

실제 사무실·직원·고객 현장·판매 제품의 촬영 사진이 아니며, 동네 일러스트는 실제 주소의 지도가 아니다. 페이지의 설명과 대체 텍스트에서도 이 구분을 유지한다. 기존 세 이미지의 출처는 [기존 에셋 기록](asset-provenance.md), 실제 제작 화면과 고객 반응의 출처·원본 일치 검사는 [증거 자료 감사](evidence-source-audit.md)에 있다.

메인 영상은 이 브랜드 이미지들을 재구성한 **15.208초 무음 영상**이다. 안경 부품 → 콘텐츠 편집 작업대 → 사진 인쇄물 → 동네 일러스트 순으로 카메라 이동과 마스크·디졸브 전환을 사용한다. 실제 고객 촬영 영상이나 사이트 조작 녹화가 아니다.

## 적용 모션

현재 런타임은 **GSAP ScrollTrigger·SplitText·Flip와 네이티브 video·dialog**를 사용한다. 실시간 WebGL/3D 셰이더를 적용한 결과물로 설명하지 않는다.

- 메인 히어로는 데스크톱 스크롤에 따라 영상 프레임이 확대되고 첫 문장이 다음 장면의 문장으로 연결된다. 제작 과정은 3개 이미지·문장이 하나의 장면으로 전환되며, 선택 버튼으로 직접 볼 수도 있다.
- 서비스 목차는 항목 선택 시 이미지 마스크가 바뀐다. 상세는 업무별 조형과 선택 버튼을 사용한다. 블로그 원고, 인스타그램 이미지 띠, 홈페이지 화면 예시는 서로 다른 전환을 사용한다.
- 회사 소개는 이미지의 잘린 영역이 열리며 소통·편집·제작을 잇는다. 문의와 위치 안내에는 느린 이미지 이동을 적용했다.
- SplitText는 제목을 줄 단위 마스크로 나누고 시간차를 둔다. 실제 자료 갤러리의 배치 전환에는 Flip을 사용한다. 자료 확대는 원본 이미지와 네이티브 dialog를 사용한다.
- 모바일과 `prefers-reduced-motion`에서는 큰 스크롤 연출을 줄이거나 정적인 구성으로 바꾼다. 페이지 본문은 빌드된 HTML에 포함하며, 영상이 재생되지 않아도 포스터와 설명을 볼 수 있다.

## 사실과 유지 범위

2026-10-09 사용자는 아래 네 수치가 현재도 사용되는 수치라고 확인했다. 원래 범위를 유지한다.

- 5,000건+ 안경 제작 사례 작성
- 100% 메인 품목 재계약률
- 98% 전문성 만족도
- 2위 에실로 얼티밋 전국 순위

이는 사용자 확인 기록이며 원자료의 독립 검증은 아니다. 별도의 집계 기간·모수·순위 대상자는 제공되지 않아 덧붙이지 않았다. 개별 고객 반응을 전체 고객 평균이나 성과 보장으로 확대하지 않는다. 상세 출처와 공개 이미지 보존 결과는 [증거 자료 감사](evidence-source-audit.md)를 기준으로 한다.

## 검수와 전달 상태

Chromium에서 12페이지 × 1440px·390px, 총 24개 기본 화면 조합을 검사했다. 페이지·콘솔 오류와 가로 넘침은 없었다. 영상은 PC·모바일 각각 일반·축소 모션·데이터 절약 3가지 조건으로 실제 재생 시간 증가, 수동 재생·정지, 화면 밖 정지와 복귀를 확인했다. 축소 모션은 7페이지씩, JS 비활성화는 메인과 블로그 상세를 두 화면 크기에서 별도로 검사했다. 회사 3페이지의 별도 검수도 수행했다.

문의 폼은 SDK 모킹과 API 차단을 사용해 기존 payload·검증·성공 후 초기화를 확인했고, 실제 문의 메시지는 전송하지 않았다. 후기·문의·제작 사례 원본은 유지했으며 배포본 62개 파일의 연결과 30개 원본 PNG의 해시를 검사했다.

홈 스크롤 왕복 CLS는 0, 전체 페이지 초기 CLS 최댓값은 0.00859였다. rAF 간격 p95는 약 16.7ms이고 데스크톱에서 83.3ms 한 번, 영상 216프레임 중 2개 드롭을 관찰했다. 모바일 검수 영상은 180프레임 중 드롭이 없었다. 이 수치는 클라우드 Chromium 측정이며 실제 휴대폰 성능을 보장하지 않는다.

픽셀 검수에서 히어로 확대 시 영상 정지 버튼이 오른쪽으로 잘리는 문제를 발견해 변형 대상을 영상으로 한정했다. 최신 빌드에서 시작·중간·끝 버튼 위치와 실제 정지를 재검수했다. 모바일 홈페이지형 블로그 상세의 반복 장식 제목을 숨겨 제작 화면을 위로 올렸고, 두 화면 크기에서 원본 열기·7개 사례·가로 넘침을 다시 확인했다. 후속 수정 근거는 [별도 검수](media-rich-hpblog-refinement.json)에 있다.

검수 범위는 [계획](media-rich-update-plan.md), 전체 측정은 [결과](media-rich-update-results.json), 시각 평가와 한계는 [QA 보고서](media-rich-update-qa.md)에 기록한다. 이전 [기초 검사](media-rich-update-baseline.json)는 변경 전 비교 기준이다. 화면 원본은 `output/playwright/media-rich-update/`에 보존했다.

실제 브라우저의 스크롤·클릭·메뉴 이동을 녹화해 `share/recordings/kotto-media-rich-desktop.mp4`(1440×900, 44.87초)와 `kotto-media-rich-mobile.mp4`(390×844, 42.60초)로 제공한다. 각 녹화의 여덟 시점 프레임을 추출해 직접 확인했다. 생성한 브랜드 영상과 사이트 조작 녹화는 별개다. 사양과 파일 일치는 [녹화 기록](media-rich-update-recordings.json)에 있다.

접속 주소와 ZIP은 [README](../README.md)의 브랜치 미리보기를 유지한다. GitHack은 현재 환경의 네트워크 정책에서 차단되므로 외부 중계 렌더링 성공을 주장하지 않는다. 공개 원본과 다운로드 파일은 게시 후 별도로 검증한다. 단일 HTML의 오프라인 검수와 외부 지도·실제 메일 전송의 온라인 요구 조건을 구분한다.

단일 HTML 간편 보기도 최초 로드 후 네트워크를 끊고 12페이지×두 화면 크기를 검사했다. 포함 영상의 실제 재생·정지·재개, 원본 30개의 정확한 URI 일치와 디코딩, 메뉴·뒤로가기·문의 서비스 쿼리가 통과했고 추가 HTTP 요청은 0건이었다. 결과는 [오프라인 검수](standalone-qa.json)에 있다. 관리형 Chromium에서 제한된 `file://` 더블클릭 실행 자체는 검증 범위에서 제외한다.
