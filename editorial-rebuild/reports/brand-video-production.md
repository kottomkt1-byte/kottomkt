# 고또마케팅 브랜드 필름

2026-10-09 제작. 홈페이지의 첫 화면에 쓰는 **15.208초 무음 브랜드 모션 영상**이다. 페이지 화면을 녹화한 영상이나 고객 프로젝트의 촬영 영상이 아니다. 별도로 제작한 브랜드 사진과 일러스트를 재구성했으며 화면에 `고또마케팅 브랜드 필름`이라고 표시한다. 실제 고객 사례나 성과를 의미하는 숫자·상호·인용문을 합성하지 않았다.

## 시각적 구성

안경 부품의 디테일 → 콘텐츠 편집 작업대 → 사진 인쇄물 → 동네 안경원의 손그림 풍경 → 첫 장면으로 연결한다. 각 이미지의 소재 질감과 촬영 각도를 살리는 로스트럼 카메라 이동을 사용한다. 전환은 왼쪽 마스크 이동, 위쪽 지면 이동, 부드러운 디졸브 순으로 이어진다. 모바일은 데스크톱 파일을 그대로 줄이지 않고 각 원본에서 주요 피사체를 다시 크롭했다.

| 시간 | 장면 | 동작 |
| --- | --- | --- |
| 0–4.2초 | 안경 부품과 측정 도구 | 1.035→1.080 배율의 느린 접근 |
| 3.4–7.6초 | 콘텐츠 편집 작업대 | 0.8초 왼쪽 마스크 전환, 완만한 후퇴 |
| 6.8–11.0초 | 사진 인쇄물과 붉은 소재 | 0.8초 위쪽 지면 전환, 디테일 접근 |
| 10.2–14.4초 | 한국 동네를 소재로 한 손그림 | 0.8초 디졸브, 매장과 거리의 관계를 보여주는 후퇴 |
| 13.6–15.208초 | 첫 장면 | 디졸브 뒤 최초 카메라 위치로 돌아가 반복 |

원본은 `public/art/optical-editorial.webp`, `content-atelier.webp`, `social-studio.webp`, `neighborhood-atlas.webp`다. 모두 이 프로젝트에서 만든 브랜드 이미지다. 마지막 동네는 실제 주소의 안내 지도가 아니다. 이미지 생성 경위는 에셋 제작 보고서에 별도로 남긴다.

## 납품 파일

| 파일 | 사양 | 파일 크기 |
| --- | --- | --- |
| `public/films/kotto-studio-desktop.mp4` | 1280×720, 24fps, H.264 Main, 15.208초 | 2,125,269 bytes |
| `public/films/kotto-studio-mobile.mp4` | 540×676, 24fps, H.264 Main, 15.208초 | 648,601 bytes |
| `public/films/kotto-studio-poster.webp` | 데스크톱 첫 프레임 | 108,286 bytes |
| `public/films/kotto-studio-poster-mobile.webp` | 모바일 첫 프레임 | 44,584 bytes |

MP4에는 음성 트랙이 없다. `yuv420p`, `+faststart`를 적용했다. 첫 프레임 포스터를 유지하므로 JS가 실행되지 않거나 동영상 로드가 실패해도 빈 화면이 되지 않는다.

재현 명령은 프로젝트 디렉터리에서 `python scripts/create-brand-film.py`다. 실행 조건은 Python 3, FFmpeg/ffprobe, libx264·libwebp 인코더다. 네트워크 호출이나 자격 증명, 외부 코드 실행은 없다. 임시 중간 영상은 시스템 임시 디렉터리에서 생성한 후 삭제한다.

## 실제 사용한 지침 및 구현

- `.agents/skills/astra-frontend-design/SKILL.md`, `references/motion-and-interaction.md`: 목적이 있는 장면 구성, 사용자 제어, 실제 브라우저 검수.
- `.agents/skills/frontend-design/SKILL.md`: 안경 업종과 콘텐츠 제작 소재를 중심에 둔 미술 방향.
- `.agents/skills/gsap-scrolltrigger/SKILL.md`: 모션 시작·종료·반응형·감소 설정 명시. 영상 내부에는 GSAP을 추가하지 않았다. 페이지 스크롤과의 결합은 부모 장면이 담당한다.

`src/brand-video.js`는 Node에서 실행 가능한 `renderBrandVideo({id, variant})`와 브라우저 초기화 함수 `initBrandVideo()`를 제공한다. `src/brand-video.css`는 히어로의 높이를 그대로 채우는 `hero`와 16:9/모바일 4:5 비율의 `feature`를 지원한다. 포스터·동영상 경로는 `window.__KOTTO_ASSETS__`를 지원해 오프라인 단일 HTML에서도 사용할 수 있다.

## 동작 규칙

- 화면에 15% 이상 들어오고 동작 감소/데이터 절약이 꺼져 있을 때만 MP4 소스를 붙여 재생한다.
- 화면 밖 또는 브라우저 탭이 숨겨지면 일시 정지한다. 사용자가 정지한 영상은 화면에 다시 들어와도 자동 재생하지 않는다.
- `prefers-reduced-motion: reduce`, `navigator.connection.saveData`에서는 포스터만 표시한다. 명시적인 재생 버튼을 누르면 재생할 수 있다.
- <=700px에서는 648KB 모바일 MP4와 모바일 포스터를 사용한다.
- 기본 재생이 차단되면 재생 버튼을 유지한다. 소스 오류에서는 포스터와 재시도 버튼을 유지한다.
- 정지/재생 버튼은 44px 이상이며 키보드와 터치로 작동하고 `aria-pressed`와 동작 이름을 갱신한다.
- 정리 함수는 관찰자와 이벤트 리스너를 해제하고 영상을 정지한다.

## 실제 검수

Python Playwright와 `/usr/bin/chromium`으로 해당 컴포넌트와 실제 MP4를 HTTP에서 실행했다. 이 검수는 격리된 미디어 컴포넌트 검수이며, 통합 홈페이지 전체 검수는 별도 QA 보고서의 범위다.

- 1440×900에서 초기 재생 시 `currentTime`이 1.493→2.303초로 증가하고 readyState 4였다.
- 390×844 + 모바일 viewport 메타 태그에서 실제 선택 소스가 `kotto-studio-mobile.mp4`이고 포스터도 모바일 파일임을 확인했다. 1.493초까지 재생되고 터치로 정지·재생됐다.
- 정지 버튼 클릭 이후 600ms 동안 currentTime이 유지됐다. 화면 밖에서 정지, 화면 안으로 복귀 후 재생을 확인했다.
- reduced-motion 및 Save-Data에서 최초 `src`가 없고 currentTime 0이었다. 명시적 재생 후에는 각각 1초 이상 실제 재생됐다.
- 오프라인 상태에서 모바일 MP4를 `data:video/mp4;base64,…` 매핑으로 제공하고 명시적 재생을 눌러 0.905초까지 진행되는 것을 확인했다.
- MP4 응답을 404로 만든 오류 검수에서 `src`가 제거되고 포스터와 `영상 다시 재생` 버튼이 유지됐다. 소스를 정상 파일로 바꾼 뒤 같은 버튼으로 재생에 성공했다.
- 브라우저 JavaScript 오류가 없었다. 정리 함수 호출 후 정지 상태를 확인했다.
- 데스크톱/모바일 각각 시작, 첫 전환, 두 번째 장면, 다음 전환, 동네 장면, 반복 직전의 6개 프레임을 추출해 직접 보았다. 화면 캡처에서 피사체 크롭과 재생 버튼·브랜드 표시 위치를 확인했다.

실기기 배터리 소모나 장시간 프레임 성능을 측정한 결과는 아니다. 모바일 파일 크기를 분리하고 화면 밖 재생을 중단하는 것으로 부하를 제한한다.
