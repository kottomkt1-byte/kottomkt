# 고또마케팅 브랜드 필름

2026-11-06 제작. 사용자가 제공한 모델 포트폴리오 사진 5장을 바탕으로 만든 **26초 홈페이지 브랜드 필름**과 **22초 무음 히어로 반복 영상**이다. 고또마케팅이 안경원을 이해하고 전문성을 고객의 언어로 전한다는 메시지를 담는다. 개별 안경 제품의 기능이나 모델 이미지 제작 서비스의 판매 조건을 설명하는 영상으로 구성하지 않았다.

사진 원본 파일은 보존하고, 영상 안에서 크롭·느린 가상 카메라 이동·화면 배치·디졸브·브랜드 타이포그래피를 편집했다. 사진 속 얼굴이나 신체 움직임을 새로 합성하지 않았으며, 별도 현장 촬영 영상도 아니다. 영상 생성 서비스를 사용한 이미지 투 비디오 제작이 아니라 로컬 Python·FFmpeg로 렌더링한 사진 기반 필름이다.

## 장면과 브랜드 메시지

전체 필름은 24fps이며 장면 사이를 0.7초 디졸브로 연결한다. 사진의 확대 배율과 구도를 완만하게 바꾸고, 타이포그래피는 천천히 등장한다. 모바일 히어로는 세로 화면과 홈페이지 본문의 위치를 고려해 별도로 구성했다.

| 시간 | 장면과 문구 |
| --- | --- |
| 0–4.4초 | 첫 모델 사진과 “안경원을 이해하고,” |
| 4.4–8.8초 | 두 번째 모델 사진과 “고객의 언어로.” |
| 8.8–13.2초 | 세 번째 모델 사진, 느린 카메라 이동 |
| 13.2–17.6초 | 네 번째 모델 사진, 느린 카메라 이동 |
| 17.6–22초 | 다섯 번째 모델 사진과 “보이는 이야기로. 기억되는 장면으로.” |
| 22–26초 | “좋은 안경원을 제대로 알리는 일.”, kotto 워드마크와 브랜드 소개 |

히어로 버전에는 영상 내부 문구와 음악을 넣지 않아 기존 홈페이지 제목·설명과 함께 사용할 수 있다. 마지막 0.8초에 첫 장면으로 디졸브하여 반복한다. 전체 필름에는 별도로 만든 앰비언트 음악이 들어간다. 외부 음원이나 샘플을 가져오지 않고, 고정된 난수 시드와 악음·패드·잔향 합성으로 구성했다. 원음은 48kHz 스테레오 PCM16이고 MP4에는 AAC 160kbps로 포함된다.

## 사진 출처와 산출물

사진은 모두 사용자가 제공한 기존 포트폴리오의 전체 해상도 WebP다. 파일은 `public/portfolio/model-images/`에 있으며 아래 순서로 사용한다.

1. `tf6032-001-women-02.webp`
2. `tf5922-020-men-03.webp`
3. `tf1381-01a-men-03.webp`
4. `tf1291-28a-women-03.webp`
5. `tf1289-01a-women-03.webp`

사진과 최종 파일의 SHA-256 및 미디어 사양은 [kotto-seen-film-assets.json](kotto-seen-film-assets.json)에 기록했다.

| 파일 — `public/films/` 기준 | 사양 | 파일 크기 |
| --- | --- | --- |
| `kotto-seen-brand-film.mp4` | 1920×1080, 24fps, 26초, 음악 포함 | 6,663,438 bytes |
| `kotto-seen-hero-desktop.mp4` | 1280×720, 24fps, 22초, 무음 | 1,859,934 bytes |
| `kotto-seen-hero-mobile.mp4` | 720×1280, 24fps, 22초, 무음 | 1,817,949 bytes |
| `kotto-seen-poster.webp` | 데스크톱 히어로 첫 프레임, 1280×720 | 71,564 bytes |
| `kotto-seen-poster-mobile.webp` | 모바일 히어로 첫 프레임, 720×1280 | 88,502 bytes |

모든 MP4는 H.264 High·`yuv420p`·`+faststart`로 인코딩했다. 두 히어로 MP4에는 오디오 트랙이 없다.

## 재현

프로젝트 디렉터리에서 실행한다. Python 3, NumPy, SciPy, WebP를 지원하는 Pillow, FontTools, Brotli와 FFmpeg/ffprobe의 libx264·AAC 지원이 필요하다. 영상용 글꼴은 `../creative-rebuild/public/fonts/NotoSerifKR.woff2`와 `PretendardVariable.woff2`에서 준비한다. 현재 로컬 환경의 Brotli 의존성은 `/tmp/kotto-film-deps`에 있으므로 아래 명령에서 해당 경로를 지정한다. 다른 환경에서는 같은 의존성을 설치한 경로를 사용하면 된다.

```bash
python scripts/create-kotto-score.py --duration 26 --output output/brand-film/kotto-seen-score.wav
PYTHONPATH=/tmp/kotto-film-deps python scripts/create-kotto-seen-film.py --preview
PYTHONPATH=/tmp/kotto-film-deps python scripts/create-kotto-seen-film.py
```

- 음악 스크립트는 `--duration`과 `--output`을 받는다. 필름 스크립트가 읽는 WAV 경로는 위 명령의 `output/brand-film/kotto-seen-score.wav`다.
- `--preview`는 대표 장면·히어로 이미지만 `output/brand-film/`에 만든다.
- 옵션 없이 실행하면 전체·데스크톱 히어로·모바일 히어로를 모두 렌더링한다. `--only full`, `--only hero`, `--only mobile`로 하나만 만들 수 있다.
- 최종 영상·포스터는 `public/films/`, 렌더링 사양과 중간 자료는 `output/brand-film/`에 저장한다. 재현 과정에서 외부 영상 생성이나 음원 서비스를 호출하지 않는다.

## 홈페이지 재생과 접근성

`src/brand-video.js`의 `renderBrandVideo({id, variant})`와 `initBrandVideo()`가 마크업·재생·정리를 담당한다. `src/brand-video.css`가 히어로와 전체 영상 대화상자를 구성한다. 포스터·영상 경로는 `window.__KOTTO_ASSETS__` 매핑을 지원한다.

- 히어로는 화면에 15% 넘게 들어오고 동작 감소·데이터 절약이 꺼져 있을 때만 소스를 붙여 무음 반복 재생한다. 화면 밖과 숨겨진 탭에서는 정지하며, 사용자의 수동 정지는 유지한다.
- `prefers-reduced-motion: reduce` 또는 `navigator.connection.saveData`가 켜져 있으면 포스터를 표시한다. 명시적인 재생 버튼은 사용할 수 있다.
- 최초 소스 선택 시 화면 너비가 700px 이하이면 모바일 MP4와 모바일 포스터를 사용한다.
- “브랜드 필름 보기”를 누를 때만 전체 MP4의 소스를 붙인다. 소리·탐색·전체화면은 기본 비디오 컨트롤로 조절한다.
- 대화상자를 열면 히어로가 정지한다. 닫기 버튼·Escape·바깥 영역 클릭으로 닫을 수 있고 초점은 원래 링크로 돌아간다. 이전에 재생 중이었다면 기존 환경 설정에 따라 재개하며, 사용자가 정지해 둔 경우 그 상태를 보존한다.
- 대화상자를 닫으면 전체 영상의 소스를 제거한다. 빠르게 닫고 다시 열었을 때 이전 닫기 이벤트가 새 영상을 중단하지 않도록 처리했다.
- JS가 없거나 dialog API를 사용할 수 없으면 같은 링크로 전체 MP4를 새 창에서 연다. 전체 영상 오류 시에도 새 창 링크를 제공한다. 히어로 오류 시에는 포스터와 재시도 버튼이 남는다.
- 정리 함수는 두 영상을 정지하고 대화상자를 닫으며, 전체 영상 소스·관찰자·이벤트 리스너를 해제한다.

## 검수 범위

산출물의 해상도·길이·오디오 트랙·faststart와 파일 해시는 자산 기록에 보존했다. 스크립트의 실제 `--help` 출력과 재현 옵션을 대조했다.

컴포넌트 검수에서는 새 경로에 **기존 MP4를 테스트 서버에서만 대체 응답**하여 재생 로직을 분리해 확인했다. 1440·390·320px 일반 모드, 390px 동작 감소, 1440px 데이터 절약, 390px JS 미사용의 6개 조건에서 클릭 전 전체 영상 요청 없음, 사용자 정지 보존, 닫기·초점 복귀, 빠른 재개방, 기본 전체화면, 오류 대체 링크와 정리를 확인했다. 페이지 JavaScript 오류는 없었다. 이 결과는 새 영상의 구도·음악·실제 배포 통합 검수 결과를 뜻하지 않는다.

실제 `kotto-seen-*` MP4·포스터를 사용한 production 홈페이지도 Chromium에서 검수했다. 1440·390·320px 일반 모드, 390px 동작 감소, 1440px 데이터 절약, 390px JS 미사용의 6개 조건을 통과했다. 실제 영상의 시간 진행·26초 본편과 22초 루프 사양·모바일 소스 선택·본편 클릭 전 요청 없음·Escape 후 초점과 재생 복귀·사용자 수동 정지 보존을 확인했고, 가로 넘침과 JavaScript 오류는 없었다. PC·모바일 첫 화면과 본편 대화상자를 캡처해 구도와 글자를 확인했다. 결과는 `reports/kotto-seen-film-qa.json`, 재현 스크립트는 `qa/brand-film-audit.py`다. 해당 스크립트는 production 폴더를 127.0.0.1:4186에서 제공한 상태로 실행한다. 실기기 Safari 검수나 음악의 청취 평가는 포함하지 않는다.

`qa/standalone.py`의 오프라인 포함 영상 검수는 새 히어로 파일명으로 갱신했으며, 경로 변경만으로 새 단일 HTML의 검수 완료를 주장하지 않는다.

## 이전 제작 자료

2026-10-09의 `kotto-studio-*` 파일과 `scripts/create-brand-film.py`는 과거 제작 자료로 남아 있다. 당시 영상은 프로젝트 브랜드 사진·일러스트를 재구성한 15.208초 무음 필름이다. 현재 홈페이지는 새 `kotto-seen-*` 파일을 참조하며, 이전 영상의 검수 수치나 원본 출처를 새 영상에 적용하지 않는다.
