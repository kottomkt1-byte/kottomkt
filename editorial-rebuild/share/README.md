간편 보기 ZIP을 풀고 `kotto-full-site.html`을 Chrome/Edge로 열면 설치 없이 12페이지를 이동할 수 있습니다. 정적 호스팅에는 `site/`의 내용 또는 배포용 ZIP을 사용하세요.

웹 미리보기는 공개 GitHub 파일의 GitHack 중계입니다. 클라우드 네트워크에서 이 중계에 접속할 수 없어 최종 외부 응답을 확인했다고 주장하지 않습니다. 자세한 검수·실행·외부 전송 제한은 [프로젝트 안내](../README.md)에 기록했습니다.

재생성: `npm run build`, `node scripts/create-share.mjs`, `python scripts/package-preview.py`. 영상은 `qa/record.py`로 실제 브라우저에서 녹화합니다.
