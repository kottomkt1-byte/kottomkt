# 스킬 로드·적용 테스트

2026-10-09. 모든 입력·결과는 검증용이며 홈페이지에 반영하지 않았다. 아래 가상 예문의 사건·성과는 고또마케팅의 실제 사실이 아니다.

검증 방식: 현재 대화의 에이전트가 설치된 각 SKILL.md를 직접 읽고 아래 입력에 지침을 적용했다. 별도 모델이나 새 Cloud 작업을 실행한 테스트가 아니다. Codex의 실제 등록은 별도 `skills/list` 응답으로 검증했다. 아래의 '통과'는 적은 수의 수동 적용 사례에 대한 판단이며 자동 선택률·전환 성과·모든 입력에서의 품질을 증명하지 않는다.

## copywriting — 명확한 기능 설명

입력: 가상 예약 도구는 예약 전날 안내 문자를 보낸다. 이 사실만으로 기능 설명과 설정 버튼 문구를 제안하라. 성과 수치는 없다.

결과:

> 예약 전날 안내 문자를 보냅니다.
>
> 버튼: 예약 알림 설정

판정: 통과. 기능과 다음 행동이 맞고 예약 취소 감소율·매출·무료 체험을 덧붙이지 않았다. 홈페이지 문안은 작성하지 않았다.

## copy-editing — 의미를 보존하는 간결화

입력: '저희는 고객의 문의에 대한 답변을 제공하고 있습니다.' 의미를 유지하며 간결하게 교정하라.

결과:

> 저희는 고객 문의에 답변합니다.

판정: 통과. 행동과 주체를 유지했고 답변 속도·전담 인력·만족도 약속을 추가하지 않았다.

## product-marketing — 공통 맥락

입력: 사용자 지정 브랜드와 리디자인 전 Git 문서로 공통 맥락을 기록하라. 없는 가격·실적·고객 인터뷰는 추정하지 말라.

결과: `.agents/product-marketing.md` v1을 만들고 전용 스킬의 `references/business-facts.md`를 단일 사실 기준으로 연결했다. 서비스·대상·문의 흐름, 출처, 작업 가설, 추가 증빙 필요 주장을 구분했다. 날짜와 변경 기록을 남겼다.

판정: 통과. 홈페이지 본문을 변경하지 않았고 맥락 문서를 사업주의 신규 사실 승인으로 표현하지 않았다. 일반 사용자 온보딩의 질문 절차를 별도로 재현한 것은 아니다.

## humanizer — 사실·격식 보존

입력(가상): '예시팀은 2026년 10월 9일 안내 문서를 발송했습니다. 해당 문서에는 상담 절차에 대한 설명이 포함되어 있습니다.' 번역투만 가볍게 다듬어라.

결과:

> 예시팀은 2026년 10월 9일 안내 문서를 발송했습니다. 해당 문서에는 상담 절차 설명이 담겨 있습니다.

판정: 통과. 날짜·이름·발송 사실·설명 대상·합니다체를 유지했다. 문장의 자연스러움을 위해 허위 경험이나 오탈자를 넣지 않았다. 수치·날짜·고유명사, 인과 방향, 부정, 직접 인용, 핵심 주장, 격식의 의미 보존 6항을 확인했다. AI 판별 확률을 산출하지 않았다.

## grammar-checker — 오류와 허용 표기 구별

입력: '문의해도 되요? 자료를 보낼수 있습니다. 첨부 파일은 10개입니다.'

결과:

> 문의해도 돼요? 자료를 보낼 수 있습니다. 첨부 파일은 10개입니다.

판정: 통과. '되어요'의 준말 '돼요', 의존명사 '수'의 띄어쓰기를 수정했다. 아라비아 숫자와 단위가 결합한 허용 표기 '10개'는 유지했다. 원본 스킬의 예시를 한국어 규정 전체로 간주하지 않았다.

## style-guide — 브랜드 표기와 종결어미

입력(검증 예문): 브랜드명은 '고또마케팅', 어조는 합니다체다. '고또 마케팅이 안내합니다. 고또마케팅이 도와줄게.'를 점검하라.

결과:

> 고또마케팅이 안내합니다. 고또마케팅이 도와드립니다.

판정: 통과. 사용자 지정 브랜드명을 기준으로 표기를 통일하고 반말을 합니다체로 바꿨다. 두 문장의 사실 범위는 늘리지 않았다. 이 예문을 실제 서비스 소개로 게시하지 않았다.

## kotto-korean-copywriter — 사업·근거 경계

실제 설치 파일을 로드한 뒤 다음 검토 요청에 적용했다. 아래 결과는 공개 카피가 아닌 검증 메모다.

| 입력 조건 | 실제 판단 | 판정 |
| --- | --- | --- |
| 문의 양식에 '50~100만원' 선택지가 있으니 월 50만원 상품이라고 표현 | 예산 입력 항목은 정가 근거가 아니다. 가격 표현은 제외하고 계약 자료 확인 필요로 분류 | 통과 |
| 예전 홈페이지의 '메인 품목 재계약률 100%'를 근거 없이 전체 고객 실적으로 확대 | 서비스 범위·기간·대상 계약·분모·분자를 확인하기 전 사용 보류. '전체 고객'으로 확대하지 않음 | 통과 |
| 고객 메시지 캡처가 있지만 공개 동의·원본 확인 자료가 없음 | 고객 식별 후기 게시 보류. 확인할 원본과 동의 범위를 기록하고 가짜 익명 후기나 임의 인용을 만들지 않음 | 통과 |
| 안경 제작 사례 작성 건수를 안경 제작 건수로 축약 | 의미가 다르므로 축약하지 않음. 기존 건수도 별도 증빙 필요 | 통과 |
| 고또마케팅을 안경 구매 고객용 SaaS로 소개 | 업종은 안경원 대상 마케팅 대행, 기본 독자는 원장님·운영자로 판단. 무료 체험 가입 문구를 가져오지 않음 | 통과 |
| 자연스럽게 보이도록 일부러 틀린 띄어쓰기를 삽입 | 오탈자는 넣지 않고 문장 구조·어휘·리듬을 편집 | 통과 |

## 미실행 범위

새 Cloud 작업에서 이름 자동완성·암시적 선택·`$스킬명`만으로의 자동 로드는 아직 검증하지 않았다. 실제 홈페이지 카피 제작·반영·배포, 실제 고객 사례 원자료 검증, AI 검출 성능 측정은 수행하지 않았다.
