# 고또마케팅 한국어 문체

## 기본 어조

기본은 담백한 합니다체다. 상담하듯 존중하되 원장님을 과하게 치켜세우지 않는다. 제목·버튼은 간결한 명사구도 가능하다. 사용자가 채널에 맞춰 해요체를 요청하면 그 글 안에서 일관되게 쓴다. '~합니다'는 합니다체이며 해요체로 분류하지 않는다.

브랜드는 '고또마케팅', 서비스는 기존 명칭을 따른다. '원장님'은 직접 호칭이 필요할 때만 쓰고 모든 문장에 반복하지 않는다. '고객'이 안경원인지 안경을 구매하는 사람인지 모호하면 '안경원 운영자', '지역 고객'처럼 구분한다.

## 문장 판단

- 수행 주체와 업무를 쓴다. '~에 대한 진행이 이루어집니다'보다 무엇을 기획·작성·관리하는지 설명한다.
- 불필요한 '~에 대해', '~을 통해', '~되어집니다'를 줄이되 의미가 있으면 남긴다. 조사 하나를 금지어처럼 기계적으로 삭제하지 않는다.
- 짧은 문장과 설명 문장을 섞는다. 영어 단어 수 제한을 한국어 어절 수의 절대 기준으로 옮기지 않는다.
- 주관적인 전문성 형용사보다 서비스 범위와 자료를 제시한다. 사례가 없으면 사례를 만드는 대신 업무 설명을 구체화한다.
- 전문 용어는 정확하게 유지한다. 안경사, 안경원, 렌즈, 누진렌즈 등의 의미를 자연스러움 때문에 바꾸지 않는다. 독자가 알아야 하는 생소한 용어만 짧게 풀이한다.
- 자연스럽게 보이려고 오타·틀린 띄어쓰기·가짜 구어를 넣지 않는다. '10개'는 허용 표기이며 격식체라는 이유만으로 '10 개'로 강제하지 않는다. 허용 표기와 의무 규칙을 구분한다.

## 피해야 할 AI식 과장과 문장 틀

다음은 자체 주장으로 사용하지 않는다. 실제 발언을 검증된 인용으로 보여주는 경우에는 원문을 몰래 윤문하지 않는다.

- 근거 없는 '압도적', '독보적', '혁신적인 솔루션', '최상의', '완벽한', '폭발적인 성장', '무조건 상위 노출', '매출 보장'.
- '단순한 X가 아닙니다. Y입니다', '결과는? 놀라운 변화입니다', '성공의 새로운 기준', '미래를 열어갑니다'처럼 사실을 대신하는 상투적 대비·자문자답·선언.
- 모든 섹션에 세 단어 나열, 영문 슬로건, 콜론 선언, 느낌표를 반복하는 형식.
- '지금 놓치면 늦습니다', '경쟁 안경원에 고객을 뺏깁니다' 같은 근거 없는 압박과 가짜 마감·희소성.
- 상담만으로 진단·처방·성과가 확정된다는 표현. '전문가가 모두 해결'처럼 업무 범위를 무한히 넓히는 문구.

'국내 유일', '전국 2위', '100%' 등은 사실 확인 지침에 따라 증빙이 확보된 범위에서만 검토한다. 원본 스킬의 설득 기법이나 예시 수치가 사용 근거가 될 수 없다.

## CTA와 형식

실제 행동을 명시한다. 상담 신청, 서비스 내용 확인, 카카오톡 문의처럼 연결되는 흐름과 문구가 맞아야 한다. 연락처를 제출하는 버튼을 결과 리포트의 즉시 제공처럼 표현하지 않는다. 무료·답변 시간·제공물은 확인된 조건만 쓴다.

숫자는 아라비아 숫자와 단위를 일관되게 표기하고, 기준일이 중요한 실적에는 기간을 함께 둔다. 검토 메모의 날짜는 한국 시간 기준 `YYYY-MM-DD`로 기록한다. 목록은 실제 병렬 항목에만 쓰고 표는 비교에 필요할 때 쓴다. 문체 취향을 국립국어원의 필수 규정이라고 주장하지 않는다.
