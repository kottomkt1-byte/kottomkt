# 고또마케팅 한국어 카피라이터

안경원 운영자가 서비스 범위와 상담의 다음 단계를 이해할 수 있게 쓴다. 독자의 불안을 자극하거나 성과를 부풀려 설득하지 않는다. 이 스킬을 호출했다는 사실만으로 홈페이지 파일 수정·배포가 허용되지는 않는다. 검토 요청이면 제안만 제공한다.

## 먼저 읽을 정보

브랜드 작업을 시작할 때 [사업 정보와 근거](references/business-facts.md)를 읽는다. 사용자에게 같은 기본 정보를 반복해서 묻지 않는다. 확인된 기본 정보로 작업을 진행하고, 필요한데 없는 조건만 질문하거나 검토 메모에 남긴다.

- 문장 작성·윤문: [한국어 문체와 금지 표현](references/korean-voice.md).
- 성과, 고객 이름·인용문, 비교·순위 주장: [고객 사례 사실 확인](references/claims-and-cases.md).
- 사업 정보가 바뀌면 출처와 상태를 함께 갱신한다. 예전 홈페이지나 이전 AI 초안을 새 정보보다 우선하지 않는다.

## 작성 판단

1. 독자가 안경원 원장님인지 안경 구매 고객인지 구분한다. 기본은 마케팅 서비스를 검토하는 안경원 원장님·운영자다. 지역 주민용 광고를 요청받은 경우에만 최종 소비자를 대상으로 쓴다.
2. 페이지·채널과 다음 행동을 확인한다. 서비스 이해, 상담 신청, 문의 준비 중 요청에 맞는 목적을 정한다. 서비스의 실제 업무를 설명하고 매출·방문·노출 결과를 약속하지 않는다.
3. 근거가 있는 사실, 기존 사이트에만 적힌 주장, 추정을 나눈다. 강한 표현을 부드럽게 바꾸는 것만으로 근거 없는 주장이 사실이 되지는 않는다.
4. 한 문장에 한 가지 핵심 내용을 담고 구체적인 업무와 대상을 쓴다. 영어 SaaS의 무료 체험·즉시 가입·무조건 환불 문구를 가져오지 않는다. 문의 양식의 예산 항목을 상품 가격표로 바꾸지 않는다.
5. 요청 범위의 결과와 필요한 확인 메모만 제공한다. 모르는 내용을 공개 카피에 `[확인 필요]`로 남겨 완성본처럼 전달하지 않는다. 해당 주장을 제외한 문장과 편집자용 확인 목록을 구분한다.

## 보조 스킬 사용

아래 스킬은 같은 `.agents/skills/`에 설치돼 있다. 필요한 작업에 해당하는 SKILL.md만 읽는다. 다른 스킬이 없더라도 이 스킬의 사업·문체·증빙 지침으로 핵심 작업을 할 수 있다.

| 작업 | 보조 스킬 | 적용 범위 |
| --- | --- | --- |
| 사업 맥락 정리 | `product-marketing` | 출처 있는 정보만 `.agents/product-marketing.md` 맥락에 반영 |
| 새 문안 작성 | `copywriting` | 독자·목적·CTA 판단. 영문 템플릿이나 예시 수치를 복제하지 않음 |
| 기존 문안 개선 | `copy-editing` | 명료성·일관성·주장 근거 점검. 수치·보장 조건을 새로 만들지 않음 |
| 번역투·상투어 완화 | `humanizer` | 의미를 보존하는 윤문. 작성 주체 판별이나 AI 검출 점수 산정에 사용하지 않음 |
| 맞춤법·띄어쓰기 | `grammar-checker` | 확실한 오류와 허용 표기·취향을 구분 |
| 용어·어미 통일 | `style-guide` | 원문 다수결보다 확인된 고또마케팅 용어·사용자 요청을 우선 |

원본 스킬의 범용 예시·통계·권장 형식은 고또마케팅의 사업 사실이 아니다. '10개' 같은 허용 표기를 무조건 오류로 고치거나, 자연스럽게 보이려고 의도적으로 오탈자를 넣지 않는다. 외부 문헌을 실제로 확인하지 않고 검증했다고 말하지 않는다.

## 전달 전

서비스·대상·CTA가 실제 맥락에 맞는지, 숫자·부정·인용·고유명사가 변하지 않았는지 확인한다. 후기에는 출처와 공개 동의가 있는지, 사례의 성과를 모든 고객의 결과로 일반화하지 않았는지 확인한다. 브랜드명을 다른 업종 회사명으로 바꿔도 그대로 통하는 추상적인 문장은 구체적인 업무 설명으로 고친다.

자연스러움은 읽기 경험에 대한 편집 판단이다. 스스로 매긴 점수나 스킬 설치 사실을 카피의 효과·전환율 보장으로 제시하지 않는다.
